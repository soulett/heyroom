# 同屋 · 合租生活管家

一个无需构建、可直接部署到 GitHub Pages 的前端 Demo。入口文件是 `index.html`。

## 已实现

- 首页：费用、值日、库存、公约状态汇总
- 费用 AA：新增费用、平均分摊、逐人标记结清、删除费用
- 清洁值日：添加任务、调整负责人、标记完成
- 公共物品：登记、消耗、补货；采购金额可同步记入 AA
- 室友公约：新增与确认
- 浏览器本地保存和重置演示数据

## 部署到 GitHub Pages

1. 创建一个 GitHub 仓库，把本目录中的 `index.html` 放到仓库根目录。
2. 打开仓库 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`，保存。
4. 等待部署完成，从 Pages 设置页复制正式网址。此后在同一仓库更新 `index.html`，网址保持不变。

这是单浏览器演示版本。数据保存在访问者自己的浏览器中，不会在不同设备或室友之间同步。
